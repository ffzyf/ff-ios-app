通过全能签安装未签名 ipa

1先装「全能签」

没有全能签的话，先去 App Store 或全能签官网安装。

全能签是一个独立的 App，负责证书、重签和信任描述文件 —— 我们不做这些。

2复制 ipa 直链

把下面的链接复制到剪贴板（这是我们托管的未签名 ipa 文件，匿名可读）。

提示：如果你的 ipa 文件名不同，把链接末尾的文件名换成你要安装的那个即可。

3在全能签里粘贴并安装

  1. 打开 全能签 App
  2. 底部标签切到「网页」（或叫「网页安装」）
  3. 在地址栏粘贴刚才复制的 ipa 直链，回车访问
  4. 页面加载后点「安装」→ 选证书 → 开始签名安装

关于签名与信任
我们只负责把 ipa 文件递到全能签手里。证书、重签、信任描述文件、设备管理授权，都是全能签那边的事—— 具体步骤和常见问题请参考全能签的官方文档。
如果安装后打不开、提示「未受信任的企业级开发者」，请在「设置 → 通用 → VPN 与设备管理」里信任对应的描述文件。

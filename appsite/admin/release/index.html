光遇简报 · iOS 未签名包分发（app.skyzyf335.top）
v1 只支持手动上传。 不会自动从 Codemagic 拉产物 —— 那需要 CM_API_TOKEN（团队级凭据，泄露等于别人能烧你的构建分钟）， 而且 Codemagic 的 Artifact 下载链接有有效期，写进 KV 几天后就是 404， 「看起来有更新但点不动」比「没有更新」糟得多。每次发版的完整流程见本页底部四步。
  • 不做强制更新（不拦启动、不当启动门）：自己的 App，用户点「稍后」就该能继续用。
  • 不做静默下载 / 后台安装（iOS 上非 App Store 渠道做不到）。
  • 不做 beta / 多渠道：channel 参数留在契约里但 v1 只认 ios，不做灰度。
  • 不做「从 GitHub Release 拉 ipa」（链接会过期，同 Codemagic 的理由）。

发布口令 可选

你已经通过了站点登录，所以留空也能发布（服务端认 ce_auth 会话）。 只有想在浏览器之外发版（curl / CI）时才需要在 Cloudflare 配 RELEASE_TOKEN 并填在这里。 口令只存在本页内存 + localStorage，不会写进任何日志。

    每次发版的完整流程 四步，第 1 步不能跳

    1. bash scripts/bump.sh patch          # MARKETING_VERSION 末位 +1，CURRENT_PROJECT_VERSION +1（两处都改，脚本保证）
2. 推到 GitHub → Codemagic 手动跑 ios-unsigned → 下 SkyApp.ipa
3. 打开 app.skyzyf335.top/admin/release/  → 过站点登录 → 输发布口令
   上传 ipa → 填版本号 3.8.1 / 更新说明 → 点发布
4. 用户下次启动或 6 小时内回前台 → 弹 sheet → 点「用全能签安装」
    第 1 步不能跳过：App 的 localBuild 直接读 CFBundleVersion， 忘了 bump 就会「发了新版但用户永远不提示」。服务端会拒收回退的 build（400 build_regression）， 但拦不住「版本号变了、build 没变」这种情形。
    只负责把 ipa 递到全能签手里 · 证书 / 重签 / 信任描述文件是全能签那边的事
